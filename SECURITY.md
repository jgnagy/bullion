# Security Policy

## Supported Versions

Security fixes are applied to the latest release. Older releases are not
maintained; upgrade to the latest version before reporting an issue.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately. Do not open a public issue
for a security problem.

Preferred channel: GitHub private vulnerability reporting for this repository:

<https://github.com/jgnagy/bullion/security/advisories/new>

If you cannot use GitHub, email the maintainer at `security@example.com`.

Please include the affected version or commit, a description of the issue,
reproduction steps, and whether it affects certificate issuance, challenge
validation, or private-key handling. Allow a reasonable window for a fix and
coordinated disclosure before publishing details.
